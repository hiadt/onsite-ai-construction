# PathGuard 最终证据包索引

本目录中的表格和图用于项目书、答辩和演示说明。所有结果均来自冻结的 `pathguard_preexec_v2.0.0` 特征和地图分组验证，不代表实车安全认证。

## 核心结果

| 文件 | 用途 |
|---|---|
| `Gate3模型训练与可信验证报告.md` | 模型训练、独立测试、OOF和边界说明 |
| `figures/held_out_roc_pr.png` | 独立地图测试的ROC/PR曲线 |
| `figures/top_k_failure_capture.png` | Top-K验证队列的失败捕获结果 |
| `figures/60次地图分组审计区间图.png` | 重复地图分组审计的区间结果 |
| `figures/permutation_importance_top15.png` | 独立测试集前15项特征重要性 |

## 表格结果

| 文件 | 用途 |
|---|---|
| `tables/model_comparison.csv` | HistGradientBoosting、ExtraTrees、Logistic Regression比较 |
| `tables/feature_group_ablation.csv` | 路线几何、坡度、速度动态、转向、净空、局部窗口消融 |
| `tables/subgroup_oof_metrics.csv` | 全量、五轴、六轴、结构未定子群指标 |
| `tables/threshold_selection_calibration.csv` | 阈值选择和开发集校准记录 |
| `tables/permutation_importance_test.csv` | 独立测试集特征重要性明细 |
| `tables/held_out_test_predictions.csv` | 独立地图测试样本的风险预测和标签，用于复核图表 |

## 使用口径

1. 模型负责相对风险排序，不宣称替代实车检测。
2. 规则风险用于工程解释、底线检查和人工复核提示。
3. Top-K结果用于说明验证资源如何优先分配，不等于所有未入选路线都安全。
4. 五轴样本表现弱于六轴，应在项目书中作为后续专项校准方向，不隐藏该结果。
5. 结构未定样本用于覆盖分析和可信拒判，不应写成已经识别出确定车型。
6. `held_out_test_predictions.csv` 只保存派生预测结果，不包含原始NPZ或原始路径数据。
