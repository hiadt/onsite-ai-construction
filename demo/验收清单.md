- [ ] 使用 `streamlit run demo/app.py` 启动；
- [ ] 无需访问外部服务器；
- [ ] 页面能在空白环境启动并显示产品名称；
- [ ] 模型状态显示为“学习模型已加载”。

## 数据与模型

- [ ] 读取 `demo/models/pathguard_gate3_model.joblib`；

- [ ] 模型缺失时明确显示规则预览，不伪装成AI推理。

- [ ] 项目总览能在10秒内说明产品价值；

- [ ] 风险队列支持地图或路线搜索；
- [ ] 每行显示模型风险、规则风险、综合优先级和下一步动作；

- [ ] 能生成Top-10、Top-20、Top-34队列；
- [ ] 结构未定样本显示人工复核提示。
