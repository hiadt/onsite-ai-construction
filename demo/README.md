# PathGuard Streamlit 统一演示

本目录提供 PathGuard 的单一演示入口，用于展示候选工程车辆路线的离线风险排序、原因解释与验证优先级安排。产品不替代闭环仿真、实车测试或安全认证。

## 启动

在仓库根目录执行：

```powershell
python -m venv .venv-demo
.\.venv-demo\Scripts\python.exe -m pip install -r demo\requirements.txt
.\.venv-demo\Scripts\python.exe -m streamlit run demo\app.py
```

浏览器默认打开 `http://localhost:8501`。旧的 `pathguard_demo.html` 已停用，不再作为产品入口。

## 输入 CSV

页面默认加载 `demo/data/sample_input.csv`。该文件由仓库内已冻结的 SHANYU000 执行前特征确定性抽取，包含五轴、六轴及通过/失败标签，不包含原始 NPZ。

上传文件必须包含 `demo/data/feature_contract_v2.json` 中按顺序定义的 55 项 `training_feature_columns`，所有值必须能转换为有限数值。元数据列可以缺省；缺省时仅用于本次演示显示，不会被当作训练特征。关键标准为：

- 特征版本：`pathguard_preexec_v2.0.0`
- 局部窗口：10 m
- 标签定义：`1=pass, 0=fail`
- Schema SHA-256：`b365d5b00779cc9f1e2858e695f0063112d94771a2cbc611c734d1110983d334`

## 模型、规则与组合风险

正式 Gate 3 模型应由项目负责人放置到：

```text
demo/models/pathguard_gate3_model.joblib
```

模型必须提供 `predict_proba` 和 `classes_`，且特征顺序与 v2 契约完全一致。失败标签固定为 0；程序不会猜测概率列。仓库当前没有 Gate 3 模型、预测结果或验证报告，因此界面会明确显示“待模型/待验证”，不会生成虚构的模型分数、组合风险或验证指标。

透明几何规则由六组执行前信息组成：曲率与变化、速度曲率耦合、转向应力、横摆应力、坡度变化、静态边界余量。各项在当前输入批次内转换为相对分位并等权汇总；它只用于预览排序与解释，不是安全概率。

模型可用时，演示组合配置为：

```text
组合风险 = 0.6 × 模型失败风险 + 0.4 × 几何规则风险
```

风险分层：高风险 `>= 0.70`；中风险 `[0.45, 0.70)`；低风险 `< 0.45`。该权重和阈值属于演示配置，必须由后续 Gate 3 验证结果校准。

## 数据与安全边界

- 模型输入只使用契约内的 55 项执行前数值特征。
- 标签、样本 ID、文件哈希、地图、路线、车型结构、来源机器和配置指纹均为元数据，不进入模型矩阵。
- 不使用证书结果、失败原因、运行后动态净空、最大滑移率、最大轮胎利用率、报告路径或构建批次作为输入。
- 示例样本来自离线冻结数据，不代表已经完成实车安全验证。
- 当前已提交的冻结特征示例不含 `unknown` 结构；结构未定入口可用于上传数据筛选。
- 仓库缺少 Gate 3 输出，暂时不能声称示例覆盖经模型验证的高风险/低风险样本。

## 生成示例数据

当冻结特征或契约更新后，在仓库根目录执行：

```powershell
python demo\build_demo_data.py
```

脚本固定选择已登记的真实样本 ID，并在版本、特征数或样本缺失时失败，避免静默生成另一套口径。
