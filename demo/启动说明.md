# PathGuard 前端启动说明

请在仓库根目录执行，不要双击 `app.py`，也不要只下载 `demo/` 子目录。

## Windows 推荐方式

在 PowerShell 中运行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\demo\start_demo.ps1
```

脚本会优先使用仓库根目录的 `.venv`，检查 Python 版本和 Streamlit；缺少依赖时安装 `demo/requirements.txt`，然后在 `http://127.0.0.1:8522/` 启动页面。

## 手动方式

项目固定依赖 Python 3.9 或 3.10。首次运行：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r demo\requirements.txt
.\.venv\Scripts\python.exe -m streamlit run demo\app.py --server.port 8522
```

## 常见问题

- `ModuleNotFoundError`：说明没有在当前 Python 环境安装 `demo/requirements.txt`。
- `InvalidVersion`、SciPy 或 scikit-learn 安装失败：通常是 Python 版本过高，请改用 Python 3.9/3.10。
- 页面空白或端口被占用：关闭旧的 Streamlit 进程，或把启动命令中的 `8522` 改成其他端口。
- 模型显示“规则预览”：确认完整仓库已拉取，并且 `demo/models/pathguard_gate3_model.joblib` 存在；不要只复制 `app.py`。
- Windows 阻止脚本执行：只对当前 PowerShell 会话运行 `Set-ExecutionPolicy -Scope Process Bypass`，不需要修改系统策略。
