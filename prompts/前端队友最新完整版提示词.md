## 项目定位

PathGuard 是工程车辆候选轨迹的离线风险排序与可信拒判原型。它在闭环仿真和实车验证之前，对候选路线进行风险排序、解释风险因素并生成验证优先级。

系统不替代实车检测，不直接控制车辆，不构成安全认证。

## 一、统一入口

保留并完善 `demo/app.py`，启动命令只有：

```bash
streamlit run demo/app.py
```

不要让评委分别打开静态网页、接口或脚本。一个 Streamlit 页面完成全部展示。

可以使用顶部Tab或侧边栏切换：

1. 项目总览；
2. 风险队列；
3. 路线详情；
4. 验证依据。

## 二、必须接入真实模型

`demo/models/pathguard_gate3_model.joblib` 存在时：

- 加载模型；
- 校验55个特征名称和顺序；
- 校验特征版本和Schema；
- 对上传CSV执行真实推理；
- 同时计算学习模型失败风险和几何应力规则风险；
- 生成综合风险和验证优先级。

如果模型文件缺失或加载失败，页面必须明确显示“学习模型未加载，当前为规则预览”，不得把规则结果伪装成AI模型结果。

默认综合风险：

```text
综合风险 = 0.6 × 学习模型失败风险 + 0.4 × 几何规则风险
```

页面注明这是演示配置，不是生产标定参数。

## 三、页面要求

### 项目总览

展示项目价值、数据规模、55维特征版本、模型状态和以下流程：

候选轨迹输入 → AI风险排序 → 几何规则校验 → 原因解释 → Top-K验证队列。

### 车辆结构

提供五轴和六轴的轻量SVG/CSS示意，并保留结构未定筛选。不要虚构车身尺寸、载荷、轮胎参数或动力学细节。

结构未定必须显示“结构未定，建议人工复核”。

### 风险队列

每条样本展示：

- 样本编号；
- 地图编号；
- 车辆结构；
- 学习模型风险；
- 规则风险；
- 综合风险；
- 高/中/低风险等级；
- 主要风险因素；
- 下一步动作。

支持按风险等级、五轴/六轴/结构未定和地图筛选，并支持Top-10、Top-20、Top-34优先验证队列。

### 路线详情

展示风险组成、特征值、风险原因、证据状态和建议动作。证据状态区分：

- final真实标签；
- 无标签指标池；
- 结构未定；
- 离线派生结果。

### 验证依据

从仓库JSON读取指标，不要手工写死新的数字。展示：

- 失败PR-AUC；
- 失败ROC-AUC；
- 全量OOF结果；
- Top-10、Top-20、Top-34失败捕获率；
- 60次地图分组审计说明。

所有指标都标注“离线地图分组验证”，不得写成实车验证结果。

## 四、风险原因

只使用当前55维特征中真实存在的字段：

- 曲率和曲率变化；
- 速度—曲率耦合；
- 横向加速度代理；
- 转向幅值和转向变化；
- 横摆角速度及其变化；
- 坡度；
- 静态边界净空；
- 10米局部窗口指标。

不要虚构滑移率、轮胎利用率、动态间隙、横向误差或航向误差。
