# PathGuard 录制同学文件拉取提示词

你现在负责录制 PathGuard 产品演示视频。请先从项目仓库的当前默认分支拉取最新代码，不要使用历史分支、旧版压缩包或 archive/iterations/ 中的材料。

仓库：`https://github.com/hiadt/onsite-ai-construction`

## 拉取与启动

1. 克隆或更新仓库，确认工作区干净。
2. 阅读 `README.md` 和 `demo/README.md`。
3. 按 `demo/README.md` 创建环境并启动 `demo/app.py`；打开启动后终端打印的本地地址。
4. 不要把电脑本地绝对路径写进视频、字幕或脚本。视频中只展示产品界面和仓库相对路径。

## 录制素材

- 演练输入：`demo/examples/recording_demo.zip`
- 解压后使用其中的12个正常NPZ、`02_车辆配置_假设五轴.json`、`04_演练检查记录_待验证.txt`。
- 异常输入和CSV只用于补充镜头：`03_异常输入_不要混入正常任务/缺少速度字段_应拒绝.npz`、`05_同批次55维特征.csv`。
- 历史执行偏差直接从页面“执行偏差实录”进入，不要把它与自制路线剪成同一段真实运行结果。

## 录制顺序

严格按《PathGuard产品演示录制稿.docx》执行：首页 → 产品介绍 → 已验证案例 → 执行偏差实录 → 新建任务 → 验证顺序 → 全程/局部与尺寸试算 → 待验证反馈 → 训练审核拦截 → 证据包导出 → 已保存任务回查 → 收尾。

## 口径要求

- 自制12条路线是功能演练输入，没有真实通过/失败标签。
- 几何扫掠是当前假设尺寸下的条件性试算，不能说成实车碰撞结论。
- 模型排序分数用于安排检查顺序，不能说成事故概率。
- 页面显示“待验证”时必须照读“待验证”，不要自行改成通过或失败。
- 关键结果停留3至5秒；加载空白可以剪掉。
