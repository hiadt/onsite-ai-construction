# PathGuard 本轮优化交付说明

## 产品与实验优化

1. **真实边界尺寸联动**：只对距离语义、左右方向/次序及保守连续性筛查均通过的边界计算局部余量；使用完整分辨率输入、四边16个横断面采样点，输出最小估算余量、位置、侧向和建议动作。结果不称为完整碰撞检测。
2. **冻结样本全量覆盖重审**：340条监督样本中69条含完整左右边界，26条通过距离语义复核，3条通过更严格点列筛查，且均为五轴。六轴不提供尺寸—边界联动结论。
3. **基线与空间证据复核**：新增已留出表上的学习模型、固定规则、最小净空和未校准50:50混合排序对照，以及地图×车型候选组代理分析。代理分析中4组、33条候选、27条失败；三个排序的同预算随机期望均高于排序捕获。旧空间预测文件逐行无差异，原“空间特征无提升”结论撤回。
4. **模型接入条件与队列**：几何越界、P0、结构未知、模型—规则冲突均进入预算外强制复核队列。模型分数、工程规则分数和几何余量继续分层；不接入未校准混合分数，不训练或发布新的空间模型。
5. **产品可解释性**：保留客户入口、产品介绍和风险工作台层级；明确示例尺寸是假设值。局部边界余量只在尺寸确认后启用，模型分数不随车长/车宽滑块改变；验证记录保存在本机SQLite，人工、仿真和实车结果不会自动上传或自动加入训练集。
