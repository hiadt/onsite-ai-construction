# 历史迭代归档

本目录保存 PathGuard 项目早期项目书、口径文件、演示交付说明和旧版图件。它们用于追溯研究过程，不作为当前演示、训练或答辩的默认入口。

## 当前主体入口

- 运行演示：`demo/app.py`
- 当前技术口径：`docs/final/PathGuard结果口径.md`
- 当前录制流程：`docs/final/PathGuard前端录制稿.md`
- 当前答辩口径：`docs/final/答辩问题与统一口径.md`
- 当前模型与数据：`demo/models/`、`demo/data/`、`data/`、`manifests/`

归档文件不参与默认运行，也不应被录制同学作为当前文件读取。若需比较演进，请以 Git 提交历史和本目录为准。
