# OnSite AI Construction

第十五届中国创新创业大赛“AI+工程机械”专业赛协作仓库。

## 当前定位

面向工程车辆候选轨迹的离线风险排序、失败原因解释与可信拒判研究原型。

当前成果基于历史数据回顾性验证，不代表实车验证结果，也不构成安全认证。

## 仓库内容

- `docs/`：项目说明、阶段报告、协作规范和结论边界。
- `prompts/`：团队共同提示词与角色任务模板。
- `manifests/`：共享数据版本、文件哈希和地图划分清单。
- `src/`：数据审计、特征、模型和演示代码。
- `configs/`：实验配置。
- `experiments/`：实验记录模板和小型指标文件。
- `reports/`：冻结的阶段报告。
- `demo/`：离线演示代码与脱敏示例。
- `tests/`：数据接口和复现检查。

## 数据规则

原始NPZ、完整路线坐标、地图、比赛工程、模型文件和专利原始证据不进入本仓库。共享数据通过受控数据目录发布，每个版本必须附数据卡、清单和SHA-256。

主分析当前使用246条独立候选路线和25张地图，验证必须按整张地图留出。
