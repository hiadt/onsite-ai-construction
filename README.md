# OnSite AI Construction

第十五届中国创新创业大赛“AI+工程机械”专业赛协作仓库。

## 当前定位

PathGuard 是面向工程车辆规划、测试和交付团队的离线候选轨迹验证优先级工作台：帮助团队排序、解释证据并安排后续验证。

当前成果基于历史数据回顾性验证，不代表实车验证结果，也不构成安全认证。模型排序、固定工程规则与真实边界几何估算是三种不同证据，不能互相替代。

当前对外唯一口径见 [`docs/final/PathGuard结果口径_v3.md`](docs/final/PathGuard结果口径_v3.md)。新版项目书见 [`Word正式版`](docs/final/PathGuard项目书正式版_v3.docx) 和 [`可编辑源稿`](docs/final/PathGuard项目书正式版_v3.md)。冻结数据为340条监督样本（139通过、201失败）、55项执行前特征、25张地图；其中五轴99条、六轴79条、结构未定162条。历史独立地图留出集为66条、5张地图；该事后对照不证明模型优于规则或批次内挑选收益。

## 仓库内容

- `docs/`：项目说明、阶段报告、协作规范和结论边界。
- `prompts/`：团队共同提示词与角色任务模板。
- `manifests/`：共享数据版本、文件哈希和地图划分清单。
- `src/`：数据审计、特征、模型和演示代码。
- `configs/`：实验配置。
- `experiments/`：实验记录模板和小型指标文件。
- `reports/`：冻结的阶段报告。
- `demo/`：离线演示代码与脱敏示例。
- `tests/`：数据接口和复现检查。

## 数据规则

原始研究数据与受限工程文件不进入共享仓库。产品演示仅保留明确标注用途的必要样例；数据版本须附数据卡、清单和SHA-256。研究结果与输入边界以 v3 口径文件和冻结数据卡为准，历史报告若与其冲突，视为已被后续审计修订的旧记录。
