# P1 客户共创工作流

## 工程师使用流程

1. 客户提供候选路线、车辆结构和当前规划配置。
2. PathGuard读取55维候选轨迹特征，执行学习模型和几何规则双重评估。
3. 系统返回综合风险、主要风险因素、证据等级和验证优先级。
4. 高风险路线优先进入闭环仿真、人工复核或实车补测；低风险路线保留抽检，不跳过安全流程。
5. 客户将复核结果、失败原因和新配置回流，形成下一轮规则与模型更新数据。

## 客户共创切入点

- 规划工程师：提前发现速度—曲率、转向变化和边界净空风险。
- 测试工程师：按Top-K队列安排有限仿真和实车验证资源。
- 主机厂/客户：对五轴、六轴和结构未定样本分别管理证据等级。
- 算法团队：利用复核结果更新风险规则、阈值和特征覆盖范围。

## 建议验收指标

- Top-10、Top-20、Top-34失败捕获率；
- 每轮需要人工或仿真的候选路线数量；
- 高风险路线中真实失败比例；
- 结构未定样本转人工复核比例；
- 新地图上的风险排序稳定性。

当前这些指标属于离线验证指标。没有客户现场数据前，材料中使用“共创验收指标”和“待现场验证”，不写成已经完成商业部署。
