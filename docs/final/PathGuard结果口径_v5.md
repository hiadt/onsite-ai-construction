# PathGuard 当前对外口径 V5

2026-09-24。V5取代旧版定位与数字，原始实验留存。

## 名称与主线

- 全名：PathGuard——多轴工程车辆轨迹风险分析与验证决策平台。
- 技术副标题：融合历史学习、车身几何与执行证据的轨迹评估方法。
- 首页主张：从规划轨迹到实际执行，让工程风险看得见。
- 价值：定位执行差距、解释车身空间变化、组织验证证据，服务规划、测试和交付协作。
- “融合”指系统级证据协同，正式产品没有加权融合风险模型。

## 能力区分

执行前分析：55维特征输入HGB模型，输出历史失败类别排序分值；独立规则提供相对开发分布的工程提示。

空间分析：长宽、参考点与路线姿态驱动刚性矩形外廓；边界和配置具备条件时才试算余量。长宽不进入55维模型，质量已移除。

执行实录：两次核对历史平台运行，实际遥测与计划路线对照，不是未来逐时刻误差预测。原时序响应表属影子研究。

## 宣传重点与证据位置

突出完整工作流、可解释参数、地图隔离实验、原始遥测核对、本地轻量接入，以及任务和验证版本关联。首页讲价值与操作结果，方法与实验章节完整说明指标条件。不要让专业限定淹没首页，也不要删去影响判断的重要事实。

可以说“历史留出前20位包含17条失败”“两次运行偏差已核对”；不能说“85%事故预测准确率”“任意车型泛化”“已节省43.6%测试”“P95保证95%”“已完成企业试点”。匿名反馈是需求输入；试点和商业模式是计划。规则提示不等于模型归因，模型规则差异没有已校准的自动冲突阈值。

## V5技术补充

本版深化数学模型、算法与架构说明，没有重新训练或替换工件。

- 实际部署工件：HGB，250轮，学习率0.04，最多15叶，最小叶样本20，L2为1；55维契约保持不变。
- 历史留出分数来自开发集内分组拟合与sigmoid校准路径；部署工件在340条全量样本上重训，未包裹校准器。不可移用历史校准阈值的可靠性结论。
- `pr_auc_failure`按代码实际含义是平均精确率AP，不是梯形积分的PR面积。
- 工程规则对16项指标按3/2/3/2/1/5分为六组，组内均值后组间等权，不是16项等权。
- 空间计算使用16个周界点和局部截面近似；已输出里程、侧别和最小余量，未持久化最危险周界点的车头/车尾分类。
- 队列普通预算K之外可有独立事项M；最终队列可超过K。

完整原理和实现追溯见 `PathGuard项目书正式版_v5.md` 与 `technical_v5/`。
